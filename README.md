# Discussion Portal App

A feature-rich, interactive Discussion App built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. This application allows users to post questions, respond to discussions, vote, favorite, and search questions in real time.

---

## 🚀 Key Features 

- **Split-Pane Layout:** Left sidebar displays all created questions, while the right pane dynamically handles question submission and detailed discussion views.
- **Submit Questions:** Users can post questions with a mandatory subject and body text.
- **Discussion & Responses:** Click on any question card to view full details, previous responses, and submit new comments with mandatory Name and Comment fields.
- **Resolve System:** Click "Resolve" on any open question to remove it from the list and return to the new question submission form.
- **Real-time Search & Highlighting:** Instantly filters questions in the sidebar as you type and visually highlights search term matches in yellow.
- **Favorites & Upvoting:**
  - Toggle star icons to mark questions as favorites. Favorited questions stay pinned at the top.
  - Upvote or downvote questions and responses. Items automatically re-sort based on vote counts.
